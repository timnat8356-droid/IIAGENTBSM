# Beauty Supply Moscow — контент-бот для Telegram-канала

Отдельный бот, не связанный с ботом обработки заказов. Раз в день (в 11:00 и 17:00 МСК
по умолчанию), а также по команде `/generate`, бот:

1. берёт случайный товар из встроенного прайса (файл `app/products.py`);
2. пишет текст поста через Claude API по бренд-гайдлайнам (без эмодзи и без тире);
3. присылает **текст вам в личку** и просит прислать фото для этого поста;
4. когда вы отправляете фото в чат с ботом — он собирает пост (фото + текст) и
   показывает кнопки **Опубликовать / Другое фото / Изменить текст / Отклонить**;
5. публикует в канал только по вашему нажатию «✅ Опубликовать».

Никаких внешних сервисов (Google Sheets, Google Drive) не нужно — прайс зашит прямо
в код, а фото каждый раз выбираете вы сами.

## Как это выглядит на практике

```
Бот: [текст поста про товар]
     📷 Пришлите фото для этого поста — просто отправьте его сюда
     [🔄 Другой товар] [❌ Отклонить]

Вы:  [отправляете фото]

Бот: [фото + текст поста]
     [✅ Опубликовать] [🖼 Другое фото]
     [✏️ Изменить текст] [❌ Отклонить]
```

Если вы копите несколько неотвеченных черновиков (например, пришли и утренний,
и вечерний, а вы ещё не ответили на первый) — присылайте фото **ответом (reply)**
на нужное текстовое сообщение, чтобы бот не перепутал, к какому черновику оно
относится. Если черновик, ждущий фото, только один — можно просто отправить
фото без reply.

## Прайс-лист

Хранится в `app/products.py` в виде списка словарей:

```python
PRODUCTS = [
    {"name": "Салфетки 10х10", "price": "35", "pack": "100 шт"},
    {"name": "Перчатки Benovy Черные M", "price": "350", "pack": "50 шт"},
    ...
]
```

Загружены все 185 позиций из вашего прайса на момент сборки бота.

**Как обновить прайс в будущем:** откройте `app/products.py`, добавьте/удалите/поправьте
нужные строки в том же формате и задеплойте изменения (просто запушьте в GitHub —
Render передеплоит автоматически). Если пришлёте мне новый прайс-лист — соберу
обновлённый файл заново.

## Что нужно подготовить перед запуском

### 1. Новый Telegram-бот
1. В Telegram напишите **@BotFather** → `/newbot` → задайте имя и username
   (например `bsm_content_bot`).
2. Сохраните токен — это `BOT_TOKEN`.
3. Добавьте бота **администратором** в канал `t.me/beautysupplymoscow`
   (нужно право «Публикация сообщений»).
4. Узнайте свой `OWNER_CHAT_ID`: напишите боту **@userinfobot** — он покажет ваш chat_id.
5. `CHANNEL_ID` — это `@beautysupplymoscow` (если канал публичный) либо числовой
   id вида `-100xxxxxxxxxx` (если приватный — его можно получить через @userinfobot,
   переслав ему любое сообщение из канала).

### 2. Anthropic API-ключ
Получите ключ на [console.anthropic.com](https://console.anthropic.com/) → это `ANTHROPIC_API_KEY`.

## Деплой на Render

1. Загрузите этот проект в отдельный GitHub-репозиторий.
2. На [Render](https://render.com) → **New → Web Service** → подключите репозиторий.
3. **Build Command:** `pip install -r requirements.txt`
   **Start Command:** `python -m app.main`
4. Во вкладке **Environment** добавьте переменные из `.env.example` со своими
   реальными значениями. `WEBHOOK_HOST` — это URL, который Render выдаст вашему
   сервису (например `https://bsm-content-bot.onrender.com`) — его нужно вписать
   вручную после первого деплоя и передеплоить.
5. После деплоя откройте бота в Telegram → `/start`, затем `/generate` — проверьте,
   что текст приходит, и после отправки фото собирается полноценный черновик.

⚠️ На бесплатном тарифе Render сервис «засыпает» при простое — учитывайте это
для автогенерации по расписанию (можно держать его «в тонусе» внешним пингом,
как и для основного бота с заказами).

## Команды и кнопки

- `/generate` — сгенерировать текст поста прямо сейчас (вне расписания).
- **🔄 Другой товар** (пока ждём фото) — отбросить этот черновик, взять другой товар.
- **✅ Опубликовать** (когда фото уже прикреплено) — публикует пост в канал как есть.
- **🖼 Другое фото** — просит прислать другое фото для этого же текста.
- **✏️ Изменить текст** — бот просит прислать новый текст, подставляет его в черновик
  (с уже прикреплённым фото, если оно есть) и показывает кнопки заново.
- **❌ Отклонить** — удаляет черновик без публикации.

Бот запоминает последние ~20 опубликованных товаров, чтобы не повторять их подряд
при случайном выборе.

## Ограничения текущей версии (что можно улучшить дальше)
- Черновики хранятся в памяти процесса — при перезапуске сервиса (например, после
  «просыпания» на Render) неотвеченные черновики потеряются. Для MVP это некритично.
- Поддержка одного канала и одного владельца-модератора.
- Фото распознаётся по `file_id` из Telegram — присылайте именно как фото
  (не как файл/документ), иначе бот его не подхватит.
- Прайс обновляется правкой файла в коде, а не «живой» таблицей — для команды
  из одного человека это обычно даже проще, чем следить за доступами к Google Sheets.
